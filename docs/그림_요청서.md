# 그림 요청서 (ChatGPT 그림 도구용)

코드로 그린 임시 그림을 바꾸기 위한 목록. 만든 파일을 아래 이름으로 `assets/`에 넣으면 된다.
동아 샘플도 코드로 그리는 것(손 모양, 스스로 평가 얼굴, 트로피, 집·소리·화살표)은 대상이 아니다.

## 공통 조건 (매번 앞에 붙임)
> 어린이 과학 교재용 3D 점토풍 아이콘. 둥글고 통통한 모양, 부드러운 광택, 파스텔 색, 옅은 그림자. 정면에서 약간 위에서 본 각도. 글자·숫자·로고 없음. 배경은 투명. 정사각형 1024×1024, 물체가 화면의 80%를 채움.

기준 그림: `assets/bg_hill.jpg`(망원경), `assets/dg_it_obs.webp`, `assets/dg_it_video.webp`(동아 샘플 아이콘). 가능하면 이 그림들을 함께 올리고 "같은 그림체로"라고 한다.

|---|---|---|---|

| `ic_journal.png` | 머리 [관찰 일지], 인트로 [이어서 하기] | 선 아이콘 / 샘플의 준비물 아이콘 | 펼친 공책과 연필. 공책 한쪽에 달 그림이 그려져 있음. 분홍·보라 계열 |
| `ic_prep.png` | 머리 [준비물] | 선 아이콘 | 체크 표시가 있는 집게판(클립보드)과 연필. 파랑·노랑 계열. `dg_it_obs.webp`와 같은 종류 |
| `ic_video.png` | 머리 [도움 영상] | 선 아이콘 | 재생 세모가 있는 영화 촬영 딱따기(슬레이트). 보라 계열. `dg_it_video.webp`와 같은 종류 |
| `prep_tablet.png` | 준비물 팝업 "스마트 기기" | 선 아이콘 | 태블릿 한 대를 비스듬히 세워 둔 모습. 화면은 꺼진 짙은 남색. 흰 배경의 실물 사진처럼(점토풍 아님) |

- `ic_prep.png`, `ic_video.png`는 동아 샘플 아이콘을 그대로 써도 된다면 만들지 않아도 된다(지금 인트로에서 이미 쓰고 있음)
- 준비물 "달 사진"은 교과서 그림 `tb_moon.jpg`를 쓰고 있어 그대로 둔다

## 받은 뒤 할 일
1. 파일을 `assets/`에 넣는다(용량이 크면 512×512 webp로 줄임)
2. `index.html`에서 해당 자리의 `<svg class="i">` 또는 `dg_it_*.webp`를 `<img>`로 바꾼다
3. `README.md` 자료 출처에 "생성형 그림 도구로 제작"으로 추가
4. `docs/템플릿_개발안내.md`의 '바뀐 기록'에 한 줄
