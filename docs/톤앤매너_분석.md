# 동아 확정 샘플 톤앤매너 분석과 적용 (2026-11-22)

대상: `실험관찰+가상실험실.html` (6학년 「압력에 따른 부피 변화 관찰하기」, 실험 차시). 1280×800에서 39개 화면 상태를 캡처해 확인함.

## 샘플의 화면 구성
| 화면 | 구성 |
|---|---|
| 인트로 | 모눈 무늬 미색 바탕. 왼쪽 위 과목·단원 알약, 오른쪽 위 교과서·실험관찰 쪽수 알약. 큰 제목(핵심어는 자주색 + 노란 밑줄). 자주색 입체 START 단추. 오른쪽 3D 점토풍 그림. 오른쪽 아래 흰 보조 단추 2개(실험영상·가상실험실) |
| 준비물·안전 팝업 | 뒤 화면 흐림. 흰 상자, 분홍 칸 2개. 준비물을 하나씩 눌러 확인, 안전 다짐 단추. 다 해야 본 화면이 열림 |
| 수업창(과정 1~4, 정리, 스스로 평가) | 머리에 탐구 활동 배지·제목·쪽수·아이콘 단추 3개·집·소리. 큰 숫자 + 지시문. 좌우 가운데 둥근 자주색 화살표로 이전·다음. 쪽 번호 없음 |
| 가상실험실 | 머리(VIRTUAL LAB 나만의 실험실, 소리, 검은 [수업창으로]). 차례 띠(준비·실험 1·실험 2, 끝난 것은 ✓). 번호 칩 + 한 문장 안내 띠. 흰 무대. 오른쪽 관찰 기록 표 + 알게 된 점 고르기. 손 모양 유도, 아래 가운데 초록 알림, 주황 경고 |
| 팝업(예상·안전·결과) | 작은 자주색 머리말 + 큰 제목 + 고르기 칸 + 단추 |

## 값
- 색: 바탕 #FBF8F3, 단원 색 #BC499B(진한 #8E2F74), 연한 #F8EBF4·#FCF5FA, 테두리 #EBD5E4, 강조 노랑 #FFE08A, 글자 #221E1F, 정답 파랑 #1E6FE0, 알림 초록 #17955A, 경고 주황 #E5622B
- 글꼴: 제목 잘난체(JalnanGothic), 가상실험실 본문 G마켓 산스, 수업창 본문 나눔스퀘어(라운드)
- 모양: 카드 둥글기 20~28px, 단추 14px, 알약 999px. 단추는 아래쪽 단색 그림자(눌리는 느낌). 다음에 누를 단추에 번지는 테두리
- 문체: 가상실험실 지시는 "~해 주세요", 예상은 "~해 보세요", 결과 알림은 "~했어요". 지시문의 핵심어만 자주색 굵게. 수업창 지시는 교과서체("~합니다", "~봅시다")
- 진행: 한 번에 한 가지 안내. 아직 못 누르는 고르기는 흐리게 보여 둠. 오답은 흔들림 + 주황 알림, 정답은 채워진 단추 + 초록 알림

## 달 관측소에 적용한 것
- 전체를 샘플의 가상실험실 틀로 바꿈: 머리 / 차례 띠(7칸, 표시만) / 번호 칩 안내 띠 + 무대 / 오른쪽 기록 / 아래 이전·다음
- 3D 달은 전체 화면 배경에서 무대 칸 안으로 옮김. 어두운 하늘은 무대 안에만 남김
- 인트로를 샘플 배치로 다시 만듦. 그림은 기존 `bg_hill.jpg`에 실제 달 모형을 한 번 그려 얹음
- 색·글꼴·둥글기·단추·팝업·알림·손 유도·스스로 평가 얼굴을 샘플 값으로 맞춤
- 지시문을 "~해 주세요/~해 보세요"로 통일. 내용과 교과서 용어는 바꾸지 않음
- 화면 왼쪽 아래 도움말(tip)과 옆 칸의 할 일 목록을 없애고 안내 띠 하나로 합침
- 고치면서 발견한 오류 수정: [이어서 하기]가 시작할 때 저장 내용을 덮어써서 동작하지 않던 것

## 샘플에 있어서 뒤이어 넣은 것 (2026-11-22)
효과음과 끄기 단추 / 눌러서 확인하는 준비물 팝업(모두 확인해야 시작) / 내 예상과 결과를 견주는 결과 팝업 / 마무리 팝업 / 초기화 단추 / 차례 띠 눌러 이동(가 본 곳만) / 무대 상태 칩(지금 보는 곳) / 다음에 누를 단추 위 손 모양 / 키보드 ←→ 이동과 초점 테두리

## 샘플과 다르게 둔 것 (판단 필요)
- 단원 색: 샘플의 자주색을 그대로 씀. 샘플 코드가 `--unit` 변수로 단원 색을 두고 있어 단원마다 다를 가능성이 큼. 밤하늘 관찰 단원 색을 받으면 `index.html`의 `--pri`, `--pri-d`와 연한 색 몇 개만 바꾸면 됨
- 이전·다음: 수업창의 좌우 둥근 화살표 대신 아래쪽 단추. 무대를 가리지 않게 하려는 것
- 안전 다짐·안전 수칙 팝업: 넣지 않음. 이 차시 교과서에 안전 항목이 없음
- 영상: 샘플은 준비·결과 영상 두 편을 탭으로 보임. 이 차시는 도움 영상 한 편뿐
- 수업창 부품(사진 위 번호 안내, 작은 탭, 괄호 속 고르기): 넣지 않음. 이 저장소는 가상실험실만 만듦
- 아이콘: 인트로와 머리 단추의 3D 아이콘은 샘플 그림체에 맞춰 새로 만든 것(`assets/ic_*.png`). 샘플 파일은 쓰지 않음
- 부품별 대응은 `docs/템플릿_개발안내.md` 2번 표
