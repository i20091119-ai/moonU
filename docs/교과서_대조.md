# 교과서·지도서 대조 (4-2 1단원 1소단원)

출처: 과학PDF_421(14~15쪽), 과학지도서PDF_421(118~123쪽), 실험관찰PDF_421(10쪽), 2022 개정 과학과 교육과정

## 교과서 본문이 말하는 것
- 달은 둥근 공 모양, 표면은 단단한 땅
- 표면은 울퉁불퉁하고 크고 작은 충돌 구덩이가 많음
- 어두운 곳과 밝은 곳이 있고, 어두운 곳을 달의 바다라고 함
- 탐구: ① 달 사진을 관찰하고 모양과 표면 이야기하기 ② 스마트 기기로 조사하기
- 과정 표기: 관찰, 자료 조사, 컴퓨터 활용 / 준비물: 달 사진(실험관찰 61쪽), 스마트 기기 / 안전 항목 없음
- "달을 직접 관찰하거나 실감형 자료를 움직여 보면서" 살펴보라는 안내 있음
- 더 생각해요: 달의 바다에 물이 없는데 '바다'라고 부르는 까닭
  - 지도서 예시 답: 어둡고 매끈매끈하게 보여 바다처럼 보여서 / 물이 차 있을 것이라고 생각해서

## 실험관찰 10쪽 정리 문장
- 망원경으로 달은 (둥근 공) 모양으로 보인다
- 달 표면은 (어두운 곳과 밝은 곳, 울퉁불퉁한 면이 있으며 충돌 구덩이를 많이 볼 수 있다)
- 도움말: 밝고 어두운 차이, 움푹 파인 곳을 주의 깊게 살펴보기
- 스스로 평가 3문항(지식·이해 / 과정·기능 / 가치·태도), 최고야·잘했어·힘내자

## 지도서
- 지도 길잡이: 달의 물리적인 성질은 다루지 않는다
- 오개념 "달은 원 모양이다" → 입체 영상·모형 제시가 지도 방안
- 대체 도입: 달 표면의 무늬가 어떻게 보이는지 자유롭게 이야기 (창의 활동 A의 근거)
- 평가 피드백(가치·태도 미도달): 3D 자료를 조작해 보게
- 시간 배분: 개념 정리 5분, 적용 및 응용 5분
- 참고 자료(교사용, 학생 본문 아님)
  - 충돌 구덩이는 주로 운석 충돌로 생긴 것으로 여겨짐
  - 지구에서는 달의 한쪽 면만 보임
  - 달의 바다는 밝은 곳보다 충돌 구덩이가 적음
  - LRO가 촬영한 달의 앞면·뒷면 사진, 달의 바다 이름 지도
- 단원 창의 활동(실험관찰 18~19쪽 예시): 다누리호 사진 전시회, 달의 충돌 구덩이 탐사하기, 달 표면 산책하기 (더 해 보기 C의 근거)

## 교육과정
- [4과13-01] 해설: 위상변화의 원인은 다루지 않고, 모양이 주기적으로 바뀌는 현상을 관찰하는 데 초점
- 고려 사항: 모형, 시청각 자료, 천체 관측 프로그램으로 호기심 유도와 공간적 이해 지원 가능
