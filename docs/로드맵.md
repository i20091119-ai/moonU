# 개선 로드맵 (v0.1 → v0.2)

v0.1의 약점: 달이 평평해 보임 / 가까이 보기가 같은 공의 확대 / 구덩이 만들기만 2D / 착륙이 그림 한 장 / 화면 꾸밈이 흔한 모양 / 망원경으로 보는 느낌 없음

효과가 큰 순서. 한 항목씩 끝내고 실제 화면으로 확인한 뒤 다음으로.

## 1. 달 표면에 내려가 보는 3D 지형 장면
- NASA 높이 자료(CGI Moon Kit의 ldem, 더 필요하면 LRO LOLA 격자 자료)에서 구덩이 주변을 잘라 지형 메시로
- 관찰 2에서 충돌 구덩이·달의 바다를 고르면 이 장면으로 들어가 둘러봄
- 끝난 기준: 구덩이 가장자리의 높낮이와 그림자가 보임. 태블릿에서 끊기지 않음
- 진행(2026-11-22): 관찰 지점 6곳 지형 장면 구현. 가장자리 높낮이와 그림자는 가상 브라우저에서 확인함. **실제 태블릿 성능은 미확인**
  - 높낮이를 실제의 2배로 나타냄(학생 화면에 한 줄로 밝힘). 과장 없이 갈지 결정 필요
  - 가장 가까이 보면 바닥 그림이 흐림(높이 자료 한 칸이 약 0.5 km). 더 가까이 가려면 LRO LOLA 고해상도 자료 필요
  - 남은 것: 조각 가장자리가 원판으로 끊겨 보임, 달 전체 화면에서 지형으로 넘어가는 전환이 암전뿐임

## 2. 착륙(C)과 구덩이 만들기(B)를 그 지형 위에서
- 탐사선 3D 모델(NASA 3D Resources 등, 조건 확인) 또는 단순 도형으로 직접 제작
- 먼지 입자 효과. B는 변수 조작 없이 유지
- 끝난 기준: 두 활동이 2D 그림 없이 3D 장면에서 진행됨

## 3. 달 품질
- 색 지도 8K 검토(용량과 비교), 높이 자료로 노멀맵 생성, 톤 매핑, 약한 빛 번짐
- 끝난 기준: 관찰 2의 가까이 보기에서 구덩이 테두리에 음영이 생기고 덜 흐림

## 4. 망원경 접안렌즈 연출
- 관찰 1 진입 시 둥근 렌즈 테두리와 초점 맞추는 전환
- 끝난 기준: "망원경으로 본다"는 것이 화면만으로 전달됨

## 5. 화면 꾸밈 통일
- 글자 단추(준비물·영상·일지)를 아이콘으로, 안내 캐릭터, 효과음, 화면 전환
- 그림은 ChatGPT 그림 도구로 한 벌로 제작(스타일 기준: `assets/bg_hill.jpg`, `lander.png`)
- 끝난 기준: 단추·팝업·일지가 한 벌로 보이고 소리는 끌 수 있음
